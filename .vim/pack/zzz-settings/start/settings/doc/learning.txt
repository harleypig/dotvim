1. Introduction                                        *learning-introduction*

This help file documents keystrokes and mappings defined in this Vim
configuration. It serves as a quick reference for both custom mappings and
useful built-in Vim commands.

Leader key: <Leader> is '\'; this configuration does not change it.

==============================================================================
2. General Mappings                                *learning-general-mappings*

<Leader>pp          Toggle paste mode, in Normal mode. There is no
                    Insert-mode toggle; bracketed paste covers pasting in
                    Insert mode.
<C-l>               Clear search highlighting and redraw screen
<Leader>y           Toggle syntax highlighting

==============================================================================
3. Editing                                                  *learning-editing*

[count]<Leader>O    Add [count] blank lines above the cursor line, staying
                    in Normal mode
[count]<Leader>o    Add [count] blank lines below the cursor line, staying
                    in Normal mode
S                   Start ":%s//g" with the cursor between the first two
                    slashes. Normal mode only; Visual-mode S is
                    vim-surround's.
Y                   Yank to the end of the line, like D and C
.                   Repeat the last change, then put the cursor where the
                    repeated change started. Changes made by plugins that
                    use vim-repeat, such as vim-surround, repeat too.
<Leader>ml          Add a modeline at the top of the buffer holding its
                    'tabstop', 'shiftwidth', 'textwidth' and 'expandtab',
                    commented with 'commentstring'

==============================================================================
4. File and Buffer Navigation                            *learning-navigation*

<Leader>b           List the buffers, then prompt for one to open

Built-in commands:
Ctrl+]              Go to function definition (requires ctags)
Ctrl+t              Return to previous location after Ctrl+]

==============================================================================
5. Quickfix List                                           *learning-quickfix*

Errors from ALE, and CoC's diagnostics through ALE, go to the quickfix list.

:QuickfixToggle     Open the quickfix window, keeping the cursor where it
                    was, or close it if it is open
<Leader>qf          Same as :QuickfixToggle
<Leader>q]          Go to next quickfix item
<Leader>q[          Go to previous quickfix item
c]                  Go to next quickfix item (only when CoC is loaded)
c[                  Go to previous quickfix item (only when CoC is loaded)

==============================================================================
6. Gutter and Display Controls                               *learning-gutter*

<Leader>signs       Toggle the sign column display
<Leader>ln          Cycle through line numbering modes:
                    - No numbers
                    - Absolute numbers
                    - Relative numbers
                    - Both absolute and relative numbers

==============================================================================
7. Terminal Integration                                    *learning-terminal*

<Leader>tt          Open terminal in a new window below current window

==============================================================================
8. Writing as Root                                             *learning-sudo*

w!!                 On the command line, expands to ":SudoWrite" when
                    vim-eunuch is loaded, otherwise to
                    ":w !sudo tee > /dev/null %". Press Enter to run it.

==============================================================================
9. CoC and Completion                                    *learning-completion*

These mappings exist only when CoC is loaded, which needs Node.js.

<Tab>               In insert mode:
                    - Navigate to next item if completion menu is visible
                    - Insert a tab at the start of a line or after
                      whitespace
                    - Otherwise trigger completion

<CR> (Enter)        In insert mode:
                    - Confirm selected completion if menu is visible
                    - Otherwise insert a new line

<C-Space>           Trigger completion

gd                  Go to definition
gy                  Go to type definition
gi                  Go to implementation
gr                  Go to references

==============================================================================
10. ALE and Formatting                                   *learning-formatting*

<Leader>fb          Fix current buffer with ALE

==============================================================================
11. Help Windows                                               *learning-help*

Help opens in a vertical split on the right, at most 80 columns wide.

In a help window:
<Return>            Follow help link
<C-[>               Go back in help navigation

==============================================================================
12. Vim Built-in Shortcuts                            *learning-vim-shortcuts*

Completion shortcuts:
Ctrl+x Ctrl+n       Word completion
Ctrl+x Ctrl+l       Line completion
Ctrl+x Ctrl+f       Filename completion
